========================================
  SecureLab Agent - Instalador Windows
========================================

1. Haz DOBLE CLIC en el archivo:
   Install-SecureLabAgent.bat

2. Acepta el Control de Cuentas de Usuario (UAC) cuando aparezca.

3. El agente se instalará en:
   C:\Program Files\SecureLab Agent

4. El servicio SecureLabAgent se iniciará automáticamente.

No necesitas abrir los otros archivos manualmente.
