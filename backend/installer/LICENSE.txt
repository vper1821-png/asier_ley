SECURELAB AGENT - ACUERDO DE LICENCIA
==========================================

Al instalar SecureLab Agent, aceptas los siguientes términos:

1. USO AUTORIZADO
   Este software está diseñado exclusivamente para monitoreo y gestión de cumplimiento.

2. PRIVACIDAD Y DATOS
   El agente recopila datos del sistema para fines de monitoreo y cumplimiento.
   Los datos son procesados de acuerdo con las políticas de privacidad de SecureLab.

3. PERMISOS
   El instalador requiere privilegios de administrador para:
   - Instalar el servicio de Windows
   - Configurar el agente para iniciar automáticamente
   - Acceder a información del sistema para monitoreo

4. RESPONSABILIDAD
   SecureLab no se hace responsable del uso indebido de este software.
   El usuario es responsable de cumplir con las leyes locales de privacidad.

5. ACTUALIZACIONES
   El agente puede actualizarse automáticamente para recibir mejoras y parches de seguridad.

6. DESINSTALACIÓN
   Puede desinstalar este software en cualquier momento desde "Programas y características".
